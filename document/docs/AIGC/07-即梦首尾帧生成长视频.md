# 即梦生成视频-首尾帧

核心步骤 `首尾帧` + `多段生成` + `剪映拼接`

 **写分镜提示词、作图、图生视频、剪辑**

## 整体思路

1. 把几分钟的内容拆成多个镜头（每段 ≤15s）。
2. 在即梦（Seedance 2.0）里一段一段生成视频：
   - 第一段：正常文生视频。
   - 后续每一段：用“上一段的最后一帧”当参考图/首帧来续写。
3. 全部导出后，用剪映（或其他剪辑软件）按顺序拼接、微调色彩和衔接
